- **The diff of what you picked.** Pick a pull request or merge request anywhere on the canvas and Diff shows its changes file by file, with added and removed lines coloured and line numbers on both sides.
- **Several picks at once.** Every picked change gets its own section; the first one is shown right away and each of the others opens with one press.
- **Big changes stay usable.** Every file is always listed with its counts, long files open in pages of lines you can step through, and if a change was too large to read in full, Diff says so.
- **Honest about what it shows.** Each diff names the commit it was read at, and an issue you picked is shown as an issue with nothing to diff, not as an error.
- **No extra login.** It reads changes through the `gh` or `glab` you are already signed in to.
